Privacy Policy

Effective October 20, 2026 · Android app com.patterniqMO.patterniq

Summary: Patterniq is an offline regular expression tool. It has no account system, no servers, no advertising and no analytics. The app does not request internet access and does not collect, share or sell any data.

Regex processing

Every pattern you enter is compiled and matched on your device. Patterns and test input are never transmitted to a server or to any third party.

Saved patterns

Patterns you save, including their names, descriptions, categories and flags, are stored in a local database on your device.

History

When history is on, Patterniq stores recently tested expressions on your device, up to 100 entries. Test input is only stored if you turn on “Include test input” in Settings; that option is off by default.

You can delete single entries, clear all history, or turn history off at any time. Turning off “Include test input” removes test input that was already stored.

Preferences

Settings such as live matching, and the last pattern you worked on, are stored locally so the workspace can be restored. Test input is never restored from preferences.

Export and import

Export writes a JSON file to a location you choose with the system file picker. That file is under your control; Patterniq does not upload it anywhere. Import reads a file you select and processes it locally. Imported content is treated as data and is never executed.

Clipboard

Patterniq only reads the clipboard when you tap a Paste button, and only writes to it when you tap a Copy button. Where Android supports it, copied test input is marked as sensitive.

Backups

Android cloud backup and device-to-device transfer are disabled for Patterniq, so the app does not copy your data to cloud storage.

Permissions

Patterniq requests no runtime permissions and does not use the network.

Deleting your data

Delete patterns and history inside the app. To remove all app data, clear Patterniq’s storage in Android settings or uninstall the app.

Children

Patterniq does not collect personal information from anyone, including children.

Changes

If this policy changes, the updated text will be published on this page and will ship with a new app version.
